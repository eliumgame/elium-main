dépôt principal) + forms-26, textedit-17, textedit-26 (diag-results.json). Rejoué ici sur le worktree pdf-rebuild

## Diagnostic de départ (2026-09-25, preuves exécutées)
Sonde : `node T1/ui-save.mjs http://127.0.0.1:3240/ <fichier> <tag> [mdp] [--note]` (ouvre, note p.1, Ctrl+S,
valide le dialogue, récupère le fichier téléchargé), puis `npx tsx --import ./register.mjs check.mts <src> <out> [mdp]`
(réouverture pdf.js + pdf-lib).

- T1-01 P0 (= save-02 / textedit-26) encrypted-owner-only.pdf, enregistré sans modification → le fichier ne s'ouvre
  plus : pdf.js « Ce PDF est protégé par un mot de passe » (la source s'ouvre sans). Toast affiché : « PDF exporté
  3 pages » → échec silencieux.
- T1-02 P0 (= save-01) encrypted-aes256-pwd-test.pdf ouvert avec « test », note ajoutée, enregistré → « Mot de passe
  incorrect » avec le même mot de passe. Toast « PDF exporté 7 pages · 1 annotation modifiables ».
  Cause (lue puis confirmée) : bytesRef = octets CHIFFRÉS, buildPdf charge avec ignoreEncryption et réécrit tout :
  anciens objets chiffrés recopiés dans des /ObjStm non chiffrés, nouvelles chaînes/flux en clair, /Encrypt conservé.
- T1-03 P1 word-contrat.pdf + 1 note → enregistrement = réécriture complète (82 265 → 73 724 o, 180 → 194 objets,
  objets recompressés en /ObjStm) ; aucun mode incrémental n'existe. Conséquence prouvée par save-03 et forms-26 :
  un PDF signé (PAdES Elium) perd sa signature au premier enregistrement (verifyPdfSignatures = [] ensuite), sans
  avertissement (exportPdf ne consulte pas engine.info.signed).
- T1-04 P1 Ctrl+S ouvre un dialogue « Exporter le PDF » puis TÉLÉCHARGE une copie (nom d'origine) : aucun vrai
  « Enregistrer » qui réécrit le fichier ouvert, pas d'indicateur modifié/enregistré, pas de protection à la fermeture,
  pas de brouillon de récupération.
- T1-05 P1 (= textedit-17) le toast de succès n'affiche jamais textBlocksSkipped / textBlocksSubstituted : une
  modification ignorée est annoncée comme un succès.
- T1-06 P2 engine.info.encrypted = !!password : un PDF owner-only (mot de passe utilisateur vide) est vu comme non
  chiffré ; aucune indication de protection/permissions.
- T1-07 P2 fidélité : à chaque enregistrement les annotations importées sont supprimées puis réécrites depuis le
  modèle (stripImportedAnnots), et le plan (signets) est entièrement régénéré même s'il n'a pas été touché
  (catalogue +/PageMode, destinations recalculées) — cf. diag/save/out/01-all.txt (catalogKeys ≠, objets ≠).
