# Documentation d'Elium

> **Version courante : 4.10.0.** Cette page est la documentation officielle
> d'Elium. Elle est installée avec l'application : vous la lisez donc hors
> connexion, dans la version exacte que vous utilisez.

Elium est une suite bureautique chiffrée. Elle sert à rédiger, calculer,
présenter, annoter des PDF, signer et vérifier des documents. Tout fonctionne
sur votre ordinateur, sans compte et sans connexion Internet.

Les documents sont enregistrés dans des fichiers **`.elium`** : un format
portable, que l'on peut chiffrer, signer et sceller.

## À qui s'adresse cette documentation

| Vous êtes… | Lisez d'abord |
|---|---|
| Utilisateur de la suite sur un PC Windows | Vue d'ensemble, Installation et prise en main, puis les modules de la suite locale |
| Utilisateur d'un Drive d'entreprise | Vue d'ensemble, puis les sections consacrées au Drive |
| Administrateur d'un serveur Drive | Les sections sur le Drive, l'authentification et l'exploitation |
| Développeur ou relecteur de sécurité | Le format `.elium`, la cryptographie, le modèle de menace, la contribution |

## Comment lire cette page

- Le **sommaire** à gauche est généré à partir des titres. Cliquez sur un titre pour y aller.
- La **recherche** filtre le sommaire.
- Les tableaux résument les réglages, les raccourcis et les états.
- Chaque module a une rubrique « Limites connues » : elle dit honnêtement ce qui n'est pas fait.

## Plan de la documentation

1. **Vue d'ensemble** : ce qu'est Elium, suite locale ou Drive, ce qui reste sur votre machine.
2. **Installation et prise en main** : MSI, exe, association des fichiers, PWA.
3. **Mises à jour automatiques** : comment l'application se met à jour, et comment revenir en arrière.
4. **La suite bureautique locale** : Documents, Tableur, Présentations, PDF, Détecteur, Parapheur, espace de travail, polices, réglages, langue, incidents.
5. **Dépannage et FAQ** : les problèmes les plus fréquents.
6. **Format, cryptographie et sécurité** : ce qui protège vos fichiers.
7. **Le Drive d'entreprise** : le serveur auto-hébergé, ses comptes, son exploitation.
8. **Référence** : confidentialité, contribution, journal des versions, annexes.
